ab inito molecular dynamics with CP2K

CP2K is an open-source souce software that supports both DFT and classical force fields. Its DFT functionality is based on the mixed Gaussian and plane waves approaches GPW and GAPW.

Here, an ab inito molecular dynamics simulation of a water box is performed with CP2K.

Convergence

With a big-enough REL_CUTOFF=60, converge the CUTOFF parameter first for a water molecule.

Too large CUTOFF values lead to poor grid distribution, the convergence region is in the middle (CUTOFF=400 is chosen).

Then the REL_CUTOFF convergence is investigated, and 60 is found to be a reasonable value.

Pre-equilibration with MACE

The water box with 27 molecules was prepared with ASE and equilibrated with a mace-mp foundation model.

import numpy as np

import ase.units as units
from ase import Atoms
from ase.build import molecule
#from ase.calculators.tip3p import TIP3P, angleHOH, rOH
from ase.constraints import FixBondLengths
from ase.io.trajectory import Trajectory
from ase.md import Langevin
from ase.optimize import LBFGS
from mace.calculators import mace_mp


# Set up water box at 20 deg C density
atoms = molecule("H2O")

vol = ((18.01528 / 6.022140857e23) / (0.9982 / 1e24)) ** (1 / 3.0)
atoms.set_cell((vol, vol, vol))
atoms.center()

atoms = atoms.repeat((3, 3, 3))
atoms.set_pbc(True)

calc = mace_mp(model="medium", dispersion=False, default_dtype="float32", device='cpu')

atoms.calc = calc

opt = LBFGS(atoms)

opt.run(fmax=0.05)


tag = 'mace_27mol_equil'


md = Langevin(
    atoms,
    timestep=1 * units.fs,
    temperature=300 * units.kB,
    friction=0.01,
    logfile=tag + '.log',
)

traj = Trajectory(tag + '.traj', 'w', atoms)
md.attach(traj.write, interval=1)
md.run(4000)

####k grid

The k grid sampling is converged in terms of energy from (2,2,2).

A well converged k grid of (4,4,4) is chosen without incurring much additional cost.
